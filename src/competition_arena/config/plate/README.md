# 车牌素材

| 文件 | 内容 | 来源 |
|---|---|---|
| `blue_template.png` | 蓝牌底板（蓝底 + 白框 + 两个安装孔 + 中间防伪金点=分隔点）| 开源项目 `hgrdfg/license-plate-generator-2` 的 `images/single_blue1.bmp`（1300x414，按 400x127 缩放）|
| `platechar.ttf` | **号牌专用字体**（内部名 `ChePai`，只含字母/数字；省份汉字用系统中文字体补）| 同上项目的 `font/platechar.ttf` |

> 用途：`tools/setup_cars.py` 生成随机车牌贴图（0.095 x 0.03 m 的号牌板）。
> 真实做法就是"省份汉字用中文字体 + 其余用号牌字体"，这里与之一致。
> 底板比例 400:127 = 3.15，与官方号牌 9.5:3 = 3.17 一致（官方素材里那张 200x81
> 的比例是 2.47，贴到 0.095x0.03 的板面上会被横向拉伸 28%）。
