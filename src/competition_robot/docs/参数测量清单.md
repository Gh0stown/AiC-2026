# 实车参数测量清单

目标：把 `config/robot_params.yaml` 里所有 `[待测]` 填成真值。
填完跑一次 `python3 scripts/gen_robot.py`，仿真里的车就和你手上的车一模一样了。

> 有实物就好办。**最省事的方式**：拿卷尺量下面第 1、2 组，
> 电机/编码器/雷达/相机直接抄型号手册第 3、5 组。
> 如果方便，把电机铭牌、雷达和相机的型号标签拍给我，我自己去查手册。

---

## 0. 先给一张俯视示意图，对照着量

```
                    ← 车头 (+x)

        FL ●────────────────────● FR        ┃
           │                    │            ┃  track  = 左右轮中心距
           │      车体           │            ┃
           │   (chassis 盒子)    │            ┃
        RL ●────────────────────● RR        ┃
           ↑                    ↑
           └──── wheelbase ─────┘
                 前后轮中心距
```

| 记号 | 对应参数 | 怎么量 |
|---|---|---|
| `wheelbase` | 前后轮**中心**距 | 前轮轴心 → 后轮轴心，量轮子侧面轴心的距离，不是轮子边缘 |
| `track` | 左右轮**中心**距 | 左轮中心 → 右轮中心，量两侧轮子的对称面 |
| `wheel_radius` | 轮子半径 | 量**外径**再除以 2。麦轮要量到辊子最外缘 |
| `wheel_width` | 轮子宽度 | 与地面接触那一段的厚度 |

## 1. 底盘几何（卷尺，5 分钟）

| 参数 | 含义 | 实测值 |
|---|---|---|
| `chassis.length` | 车体长（x，前后，**不含**两侧凸出的轮子） | ______ m |
| `chassis.width` | 车体宽（y，左右，**不含**轮子） | ______ m |
| `chassis.height` | 车体高（z，**不含**雷达/相机凸起） | ______ m |
| `chassis.ground_clearance` | 底盘最低点离地间隙 | ______ m |
| `chassis.mass` | 整车质量（电池 + 工控机 + 雷达相机全装上，站体重秤） | ______ kg |
| `chassis.com_offset` | 重心相对几何中心的偏移 [x, y]，大致估；量不准就填 `[0, 0]` | [____, ____] m |

> `ground_clearance` 很重要：**仿真里底盘离地间隙不对，车会拖地走不动**。

## 2. 麦轮（卷尺）

| 参数 | 含义 | 实测值 |
|---|---|---|
| `mecanum.wheel_radius` | 轮子外径 ÷ 2（量到辊子最外缘） | ______ m |
| `mecanum.wheel_width` | 轮子宽度 | ______ m |
| `mecanum.wheelbase` | 前后轮中心距 | ______ m |
| `mecanum.track` | 左右轮中心距 | ______ m |
| `mecanum.roller_count` | 每个轮子上的辊子个数（数一下，一般 8~10） | ______ |
| `mecanum.roller_angle` | 辊子倾角，标准件都是 45° | 45 |

> 顺带确认一下**轮子布局是 X 型还是 O 型**：
> 把车翻过来看，左前轮的辊子如果和右后轮同向、和右前轮反向，就是 X 型（最常见）。
> 如果反了告诉我，我把运动学的符号改掉。

## 3. 电机 + 编码器（查手册，或看电机铭牌）

| 参数 | 含义 | 实测值 |
|---|---|---|
| `encoder.counts_per_rev` | 编码器每圈脉冲数（铭牌上常写 PPR / CPR） | ______ |
| `encoder.gear_ratio` | 减速箱减速比（铭牌上常写 1:30 之类） | ______ |
| `encoder.quadrature` | 倍频：1 / 2 / 4（四倍频填 4） | ______ |
| `mecanum.max_wheel_rpm` | 轮子（输出轴）最大转速 | ______ rpm |

> 这三个数决定"车轮转一圈 = 多少计数"，
> 也就决定了里程计的标定系数，填错里程计会整体偏大/偏小。

## 4. 速度上限（能测就测，测不了按电机额定估）

| 参数 | 含义 | 实测值 |
|---|---|---|
| `mecanum.max_linear_vel` | 最大前进速度 | ______ m/s |
| `mecanum.max_lateral_vel` | 最大横移速度（麦轮横移一般比前进慢） | ______ m/s |
| `mecanum.max_angular_vel` | 最大自转角速度 | ______ rad/s |

> 实在不好测就填个保守值（比如 1.0 / 0.8 / 2.0），
> 我把它当成仿真里的 `cmd_vel` 限幅，不影响正确性。

## 5. 传感器（型号 + 安装位置）

三个传感器都要给我**相对车体几何中心的安装位置** `(x, y, z)`：
x 往前为正，y 往左为正，z 从车体几何中心往上为正。

| 传感器 | 型号 | mount (x, y, z) | 备注 |
|---|---|---|---|
| 3D 激光雷达 | ____________ | (____, ____, ____) | 还要手册上的：线数 / 垂直视场角 / 测距范围 / 出点频率 |
| 深度相机 | ____________ | (____, ____, ____) | 还要手册上的：分辨率 / 水平视场角 / 测距范围 / 帧率 |
| IMU | ____________ | (____, ____, ____) | 尽量贴近车体几何中心 |

**怎么量安装位置**：先找到车体的几何中心（长宽高的中点），
从那里量到传感器**外壳几何中心**的三个方向距离。

> 如果觉得"从几何中心量"别扭，也可以直接告诉我
> 「雷达离地 xx cm、离车头 xx cm、离左右居中」，
> 我帮你换算成相对几何中心的值。

## 6. 顺便确认两件事

1. **轮子转向**：手动把车往前推，四个轮子是不是都朝同一方向转？
2. **电机编号 ↔ 位置对应**：驱动板上的 M1/M2/M3/M4 分别接的是哪个轮子？
   这个决定运动学里四个轮速的符号，装反了车会原地打转或者斜着跑。
